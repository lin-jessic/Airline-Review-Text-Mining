Threshold and Method Comparison

為什麼最後選整段 Review？

雖然逐句平均可以避免長評論正負情緒互相抵銷，但實際驗證結果顯示，整段 Review 的 accuracy 明顯較高。

為什麼保留原生 VADER？

航空詞彙調整後的 accuracy 沒有明顯提升，代表許多航空評論的情緒來自整體語境，不只是單一航空詞彙。

BERTopic Analysis

BERTopic 主題分析結果

BERTopic 使用 sentence-transformers 將評論轉為語意向量，自動找出語意相近的抱怨主題，不需要事先指定主題數量。

BERTopic 主題分布表

Topic -1 雜訊堆說明

BERTopic 使用 HDBSCAN 分群，語意不夠集中的評論會被歸入 topic -1。本次共有 4,300 筆（43%）被歸入雜訊堆，這是 BERTopic 的正常現象。

BERTopic 的優勢

BERTopic 自動找出 40 個語意群組，比 LDA 的 7 個主題更細緻，能區分出延誤問題的子類型與行李問題的細分。

LDA 的優點

7 個主題清楚易懂，每個主題筆數多，統計穩定，適合管理者快速掌握主要抱怨類型。

BERTopic 的優點

40 個主題更細緻，能區分 LDA 合併在一起的子主題，基於語意而非詞頻，不受詞形變化影響。

Contradictory Passengers

矛盾旅客分析

分析評分 5-10 分但不推薦的旅客，找出他們與一般不滿意旅客（1-4 分不推薦）的關鍵字差異。

矛盾旅客的特徵

矛盾旅客的關鍵字以飛行體驗為主（food、cabin、crew、good），正面詞彙出現頻率高，代表他們整體體驗還可以，但特定缺點讓他們無法推薦。

一般不滿意旅客的特徵

一般不滿意旅客的關鍵字以問題導向為主（hour、customer、never、told、delayed），反映強烈的系統性不滿。

RQ3 Analysis

跨航空公司與時間的抱怨模式比較

分析不同航空公司和時間段的抱怨關鍵字，找出 industry-wide 問題和 airline-specific 問題。

Airline Comparison

前10大航空公司抱怨關鍵字比較

flight、hour、time、seat、bag、service 等詞在所有航空公司都出現（industry-wide），而 istanbul、denver、abu dhabi 等地名只在特定航空公司出現（airline-specific）。

Industry-wide 問題

延誤（flight、hour）、行李（bag）、座位（seat）、客服（service）是所有主要航空公司共同面對的抱怨，代表這些是航空業系統性的服務問題。

Airline-specific 問題

地名和樞紐城市高度集中在特定航空公司，例如 istanbul（Turkish）、denver（Frontier）、abu dhabi（Etihad），反映旅客對特定航線的不滿。

Temporal Comparison

疫情前中後抱怨主題變化

比較 2013-2019（疫情前）、2020-2021（疫情期間）、2022-2023（疫情後）三個時期的抱怨關鍵字差異。

疫情前（2013-2019）

抱怨集中在飛行體驗：seat、food、plane、staff，旅客在意機上服務品質。

疫情期間（2020-2021）

refund 突然躍升，cancelled 出現，反映大量航班取消和退款困難。customer service 首次進入前15名。

疫情後（2022-2023）

bag 問題突然增加（可能因地勤人力短缺），customer service 和 ticket 問題持續，never 情緒更強烈。
